뉴스레터 에디터

카테고리와 SNS를 자유롭게 추가/삭제하고, 필요한 섹션만 펼쳐서 편집할 수 있습니다. 생성된 HTML은 그룹웨어/메일 에디터에 붙여넣어 사용하세요.

기본 설정

푸터 SNS

기본 아이콘은 Home/Facebook/LinkedIn/YouTube에 최적화되어 있습니다. 그 외 SNS는 기본 링크 아이콘으로 표시됩니다.

메인 콘텐츠

저장 발행일 선택

같은 날짜 / 같은 언어의 저장본은 마지막 저장본으로 업데이트됩니다.

사용 가이드

한 화면 제작

입력, 미리보기, 아카이브 저장, HTML 내보내기를 한 화면에서 처리합니다.

발행일 기준 저장

저장 버튼을 누르면 발행일 선택 팝업이 열리고, 날짜별로 저장본을 관리합니다.

빠른 시작 뉴스레터를 만드는 기본 작업 순서 ⌄
1 KOR / ENG 선택

제작할 언어를 먼저 선택합니다. 언어별 기본 링크와 푸터 정보가 자동 반영됩니다.

2 메인 콘텐츠 입력

배너 이미지, 제목, 본문, CTA 링크를 입력합니다.

3 카테고리 작성

비디오, 인포그래픽, 블로그, 보도 자료 등 필요한 섹션만 편집합니다.

4 미리보기 확인

오른쪽 미리보기에서 실제 발송 형태를 확인합니다.

5 저장 / 복사 / 다운로드

작업본은 아카이브에 저장하고, 최종본은 HTML 복사 또는 다운로드로 내보냅니다.

주요 버튼 설명 화면에 있는 버튼들의 역할 ⌄
왼쪽 원형 버튼

편집 패널을 접거나 펼칩니다. 접으면 미리보기 화면이 더 넓게 보입니다.

달력 버튼

뉴스레터 아카이브를 열어 날짜별 저장본을 확인합니다.

? 가이드

현재 에디터 기능과 사용 방법을 확인합니다.

저장

저장 발행일 선택 팝업을 열고, 선택한 날짜 기준으로 저장합니다.

HTML 복사

현재 뉴스레터 HTML을 클립보드에 복사합니다.

HTML 다운로드

KOR/ENG에 따라 지정된 파일명으로 HTML을 저장합니다.

저장 발행일 선택 저장할 날짜를 선택하는 방법 ⌄
저장 버튼 클릭

저장 버튼을 누르면 바로 저장되지 않고, 먼저 발행일 선택 팝업이 열립니다.

연 / 월 / 일 선택

각 항목은 아래 방향으로 열리는 커스텀 드롭다운입니다.

최대 5개 표시

드롭다운은 약 5개 항목만 보이고, 나머지는 내부 스크롤로 선택합니다.

저장하기

선택한 날짜 기준으로 KOR/ENG 저장본이 아카이브에 저장됩니다.

  • 같은 날짜 / 같은 언어로 다시 저장하면 이전 저장본은 마지막 저장본으로 업데이트됩니다.
  • 달력에서 날짜를 선택한 뒤 저장하면 해당 날짜가 저장 발행일의 기본값으로 반영됩니다.
뉴스레터 아카이브 사용법 저장본을 찾고 다시 불러오는 방법 ⌄
선택된 날짜
오늘 날짜
저장된 날짜
  • 아카이브를 처음 열면 오늘 날짜가 파란색으로 선택됩니다.
  • 저장된 날짜에는 작은 파란 점이 표시됩니다.
  • 다른 날짜를 클릭하면 그 날짜가 파란색으로 선택되고, 아래 목록이 해당 날짜 저장 항목으로 바뀝니다.
  • 연/월 표시를 누르면 연도와 월을 직접 선택할 수 있습니다.
  • 다른 달을 보고 있을 때는 오늘 보기로 현재 달로 돌아갈 수 있습니다.
카테고리 편집 팁 섹션을 더 빠르게 관리하는 방법 ⌄
카테고리 추가

상단 입력창에 새 카테고리명을 입력하고 카테고리 추가를 누릅니다.

접기 / 펼치기

작업 중인 섹션만 열어두면 왼쪽 패널을 더 깔끔하게 사용할 수 있습니다.

아이콘 자동 매칭

블로그, 비디오, 보도 자료, 고객 사례 등 이름에 따라 아이콘이 자동 적용됩니다.

푸터 SNS 편집

Home, Support Hub, Facebook, LinkedIn, YouTube 링크를 직접 수정할 수 있습니다.

저장 및 발행 참고사항 작업 손실을 줄이기 위한 체크 포인트 ⌄
  • 페이지를 다시 열면 가장 최근 저장본이 자동으로 로드됩니다.
  • 저장 데이터는 Google Sheets 아카이브에 보관됩니다.
  • Google Sheets API 연결이 실패하면 브라우저 임시 저장본을 사용합니다.
  • 중요한 발행본은 아카이브 저장과 함께 HTML 다운로드 파일도 별도 보관하는 것을 권장합니다.
